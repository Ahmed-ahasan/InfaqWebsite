System Design

UOB DocChain is designed with a secure architecture that supports document submission, verification, blockchain-based tracking, and user access management.

01

Document Upload

Users upload academic documents to the system for processing.

02

Verification

The system checks document details and prepares them for secure validation.

03

Blockchain Record

Verification records are stored in a tamper-resistant blockchain structure.

04

Public Access

Authorized users can verify documents quickly and transparently.
